# 个人学习方法论

## 核心原则
1. **笔记先行**：学习新知识点先记导图笔记，再动手写代码验证
2. **每日一练**：保持每天写一个小练习（详见 everyday 系列）
3. **代码+笔记一体化**：代码练习与思维导图笔记同步，加深理解
4. **结构化归档**：所有资料按语言分类归档，便于回顾

## 学习流程
1. 阅读官方文档或课程 → 2. 画 XMind 思维导图 → 3. 编写练习代码 → 4. 归档到 GitHub

## 工具链
- 笔记：XMind、Markdown
- 编程：IntelliJ IDEA、VS Code、Visual Studio
- 版本管理：Git + GitHub
