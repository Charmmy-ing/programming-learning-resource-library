## 1. 计算机的存储规则

- **最小存储单元：字节（byte）**
  - 一个字节 = 8 个 bit
- **任意数据都以二进制存储**

---

## 2. 标识符（自己起的任何名）

> 备注：类名、变量名、方法名

### 硬性要求（规定）
- 只能由数字、字母、下划线、美元 `$` 字符组成
- 不能以数字开头
- 不能是关键字
- 区分大小写

### 软性命名
- **大驼峰命名**（类名用这种方法）
  - 一个单词首字母大写；多个单词每个单词开头大写
- **小驼峰命名**
  - 一个单词全部小写；多个单词第一个单词小写、其余大写

---

## 3. 方法

- 能完成特定任务和操作的**代码块**
- 格式：`修饰符 返回类型 方法名(形参列表)`
- 有的方法要接收数据，有的方法不返回数据
- 方法可以**重载**（一个方法名可以定义多个方法）
- 无返回值的方法中，`return` 可以让方法立刻结束

---

## 4. 类型转换

- 类型范围小的变量可以直接赋值给大范围类型；**大范围转小范围要强制类型转换（可能数据溢出）**
- 浮点数转整数：直接取整数部分，舍弃小数
- **表达式自动类型转换**
  - `byte`、`short`、`char` 直接默认为 `int` 参与运算，结果以最大范围类型输出
  - 注意：IDE 中整数默认是 `int` 类型，传形参时可能与方法中的形参类型冲突报错

## 8. 运算符

### 算术运算符
- `+ - * /`
  - 计算机中小数计算可能不精确（与科学计数法的存储方式有关）
  - 同类型运算得到同类型
- `%`（取余）：可以用来玩拆数游戏
- **数字计算**
  - 类型不一样不能直接运算
  - **隐式转换**（小转大：byte→short→int→long→float→double）
    - `byte`/`short`/`char` 运算时都会隐式转成 `int`，就算两个 byte 相加结果也是 int（`byte + byte = int`）
    - `byte + double = double`
  - **强制转换**（大转小，可能导致精度丢失/溢出）
    - `int a; byte b = (byte)a;`
    - `byte a; byte b; byte c = (byte)(a + b);`
- **字符运算**（ASCII 码表）
  - `A=65`，`a=97`，差 32
- **字符串运算**
  - 字符串运算只有 `+` 操作
  - 任意数据 + 字符串 = 拼接结果（从左到右拼接）
    - 例：`123 + "aaa" = "123aaa"`
    - 例：`10 + 8 + "aaa" = "18aaa"`（10+8 没有字符串参与，先算数字）
    - 例：`15 + "aaa" + 1 + 2 = "15aaa12"`

### 自增自减运算符
- `++` 和 `--`
- `a++` 与 `++a` 的区别：
  - `a++`：先使用 a，再加 1
  - `++a`：a 先加 1，再使用

### 赋值运算符
- `=`、`-=`、`+=`、`*=`、`/=`、`%=`

### 关系运算符
- `>=`、`<=`、`==`、`!=`、`>`、`<`

### 逻辑运算符
- `&`、`|`、`!`、`^`（异或：相同为 false，不同为 true）
- `&` 与 `&&` 的区别：`&&` 是短路判断，左边为 false 就不再继续执行
- `||` 也是短路判断，左边为 true 就不再执行右边

## 9. 键盘录入（Scanner）

- 位于 `java.util` 包中
- **导包**：`Scanner sc = new Scanner(System.in);`（先声明 Scanner）
- 常用方法：
  - `sc.nextDouble();` — 接收小数
  - `sc.nextInt();` — 获取键盘整数
  - `sc.next();` — 接收字符串

## 11. 变量

> 备注：变量是存储数据的小空间，不是里面的数据；是经常发生改变的量

- 格式：`数据类型 变量名 = 数据量;`
- **注意事项**
  - 只能存一个值
  - 变量在使用前一定要赋值
  - 变量名不允许重复定义
  - 一条语句可以连续赋值
